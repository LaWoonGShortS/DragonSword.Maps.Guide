                      📋 사용법
================================================================================

■ 맵 조작
  - 드래그: 이동 / 휠: 확대축소 / 더블클릭: 빠른 확대
  - 맵 클릭: 좌표 확인 (맵 바깥 클릭 방지)

■ 마커
  - 클릭: 획득 체크 (반투명) / 재클릭: 해제
  - 호버: 툴팁 표시
  - 진행도 브라우저 자동 저장

■ 필터 (다중 선택)
  - 타입별 버튼 클릭으로 표시/해제
  - 여러 타입 동시 선택 가능
  - 타입 선택 시 해당 캐릭터 커서로 변경

■ 검색
  - 키워드 입력 → 실시간 필터링

■ 좌표 제보
  - 맵 클릭 → 타입/설명 입력 → 추가 → 📋 전체 복사

■ 배경음악
  - 하단 🎵 버튼 (8곡, 재생/정지/이전/다음/볼륨)

■ UI
  - ◀ 버튼: 전체 UI 숨기기/보이기
  - 패널 헤더 클릭: 접기/펼치기
